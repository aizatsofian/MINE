Ada Data, Tetapi Masih Susah Membuat Keputusan?

1

Sistem Hanya Mengumpul Data

Banyak organisasi sudah mempunyai sistem tetapi sistem tersebut lebih tertumpu kepada pengumpulan, penyimpanan dan paparan data. Data ada tetapi analisis masih terhad.

2

Ada Banyak Data Tetapi Tiada Big Picture

Ribuan row data tidak semestinya membantu seseorang memahami apa yang sedang berlaku. Pengguna masih perlu mencari sendiri trend, perbandingan dan pola penting.

3

Reporting Ada, Analytics Tiada

Sesetengah sistem boleh menghasilkan table atau laporan tetapi tidak menyediakan analisis interaktif. Pengguna tahu apa data yang ada tetapi sukar mengetahui apa yang data itu sedang beritahu.

4

Sukar Melihat KPI dan Trend

Pengurusan mahu melihat KPI, pencapaian, trend, perbandingan, prestasi, perubahan dan perkara yang memerlukan perhatian — tetapi sistem sedia ada tidak menyediakannya.

5

Analisis Masih Manual

Pengguna terpaksa Export Excel → Filter → Formula → PivotTable → Chart → Screenshot → Report, dan proses yang sama perlu dilakukan berulang kali.

6

Kos Upgrade Sistem Tinggi

Menambah modul analytics kepada sistem sedia ada boleh memerlukan kos pembangunan tambahan. Sesetengah organisasi tidak mempunyai bajet untuk meminta vendor membangunkan modul analytics baharu.

7

Sistem Dibina Untuk Operasi, Bukan Analytics

Sistem asal mungkin sangat baik untuk operasi harian tetapi tidak semestinya direka untuk management analytics dan decision support.

8

Data Tidak Digunakan Sepenuhnya

Data telah dikumpulkan selama berbulan atau bertahun tetapi sebahagian besarnya hanya menjadi rekod. Potensi data tersebut untuk menghasilkan insight masih belum digunakan sepenuhnya.

About Dr Excel

Dr Excel ditubuhkan pada tahun 2022 sebagai satu inisiatif untuk membantu individu dan organisasi menggunakan data dengan lebih baik.

Inisiatif ini bermula selepas melihat banyak data dikumpulkan tetapi tidak diurus, dianalisis atau digunakan sepenuhnya. Keadaan ini boleh menyebabkan laporan penting tidak tersedia, keputusan dibuat tanpa analisis yang mencukupi, penggunaan sumber dan kewangan kurang tepat, pola penting dalam data tidak dikenal pasti, dan data yang dikumpulkan tidak menghasilkan insight.

Melihat kepada jurang tersebut, Dr Excel mula membantu klien menyusun, menganalisis dan memvisualisasikan data supaya data boleh ditukar kepada insight yang berguna. Insight tersebut boleh membantu dalam decision making, polisi, pengurusan, sistem, operasi, kewangan, monitoring dan reporting.

Soalan Lazim (FAQ)

Adakah saya boleh cuba dashboard sebelum membeli?

Ya. Anda boleh menekan butang "Cuba Demo" pada mana-mana kad dashboard untuk melihat dan mencuba fungsi sistem sebenar sebelum membuat pembelian.

Berapa harga setiap dashboard?

Setiap dashboard ditawarkan dengan dua pilihan: RM90 (Setup Sendiri — anda terima fail, README dan template Google Sheet) atau RM180 (Dr Excel Setupkan — kami bantu setup coding, Google Apps Script, Google Sheet dan sambungan database), kecuali jika dinyatakan sebaliknya.

Apa yang saya akan terima selepas pembelian?

Untuk pakej RM90, anda akan menerima fail sumber (HTML, CSS, JS), README dan template Google Sheet. Untuk pakej RM180, Dr Excel turut membantu setup berkaitan Google Apps Script, Google Sheet dan sambungan database mengikut skop dashboard yang dibeli.

Adakah dashboard boleh diubah (customize)?

Ya. Kod yang diberikan adalah terbuka. Anda bebas untuk mengubahsuai design atau menambah fungsi mengikut kepakaran anda, atau hubungi Dr Excel untuk Custom Dashboard.

Bagaimana saya menerima dashboard selepas bayar?

Pembayaran dibuat melalui DuitNow QR. Selepas membuat pemindahan wang, hantar bukti resit melalui WhatsApp. Fail dashboard atau setup akan diberikan kepada anda melalui WhatsApp atau Email selepas pengesahan.
